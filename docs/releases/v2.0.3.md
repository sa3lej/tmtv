## The relay keeps moving.

tmtv 2.0.3 fixes an IPC readiness race that could block the server's accept loop. Existing terminal sessions stayed alive, but new SSH connections, web viewers, and `/healthz` could stop responding. Registration reads now use a per-call non-blocking receive and handle transient `EAGAIN` without dropping the live session.

### Also included

- Fixed implicit function declarations for stricter compilers.
- Refreshed homepage documentation for shared clipboard and SIXEL support.
- Fixed Intel macOS builds by using a native Intel runner and its existing Homebrew, with explicit architecture and shared-library checks.
- Release publication now requires all builds and deployments to succeed, validates all 12 binary assets, generates `SHA256SUMS`, and checks the uploaded asset set before publishing the draft.

### Downloads

Client binaries are provided for macOS arm64 and amd64, and Linux amd64, arm64v8, arm32v7, arm32v6, and i386. Server binaries are provided for all five Linux architectures. Verify downloads against the attached `SHA256SUMS` file.

### Replacement release

The original v2.0.3 release had no binary assets because the Intel macOS dependency step failed. It has been replaced, keeping version 2.0.3 as requested by the maintainer; the tag now includes the CI and publication fixes. If you fetched the previous tag, refresh it with `git fetch --force origin tag v2.0.3`.
