## Preview announcement (historical, before release)

We're preparing tmtv 3.0: a tmux 3.8 core, richer shared terminal state, and Unicode
input that carries what you typed. tmtv lets you pair over SSH, invite browser
observers, and keep using your own terminal tools.

This is a coordinated host-and-relay upgrade. The current stable release remains
2.0.4; wait for the announced public-service cutover before switching your host.

Release preview: https://tmtv.se/releases/3-0/
Source: https://github.com/sa3lej/tmtv

## Publication announcement — use after release

**tmtv 3.0 — Your terminal. Better together.**

Pair on a fix. Walk through a failing command. Teach a workflow live.
tmtv shares your terminal over SSH, with an optional browser viewer for guests
who would rather open a link.

3.0 moves to tmux 3.8 and brings richer reconnect snapshots, portable Unicode
keystrokes and literal UTF-8 paste. Supported layouts, text attributes, hyperlinks
and SIXEL images carry more of the session's context to your guests.

Open source. Self-hostable. Separate read-only and read-write access.

**Upgrading?** The public relay is on 3.0.0. Save work before restarting your
host and distribute its new invitation links. For self-hosting, upgrade matching
host and relay versions together. See the release notes for limits and rollback guidance.

https://github.com/sa3lej/tmtv/releases/tag/v3.0.0

The public relay was upgraded to 3.0.0 on 27 October 2026.

## Short community introduction — use after release

I build tmtv, an open-source terminal-sharing tool based on tmux. It supports SSH
collaborators and an optional browser viewer, with separate read-only and read-write
access. Version 3.0 moves to tmux 3.8 and improves shared terminal state and Unicode
input. I'd welcome feedback from people who pair, troubleshoot or teach in terminals—
especially on the first-session experience and the upgrade documentation.

Source and release notes: https://github.com/sa3lej/tmtv

## Demonstration script

Use a disposable session and synthetic data. Start tmtv; show the invitation;
join from a second terminal; type together; invite a read-only browser observer;
show a small Unicode example. Finish with the website and a clearly visible version.
Keep tokens out of reusable screenshots, and end the disposable session afterwards.

Reconnect can be a separate technical clip with the final candidate. Show an actual
network interruption and restoration of supported state, and distinguish that from
a full host restart. Do not simulate an outcome the candidate has not demonstrated.
